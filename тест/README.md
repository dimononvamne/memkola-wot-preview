# MEMKOLA WOT — GitHub Pages preview

Static preview from the complete build dated 2026-10-26.

GitHub Pages serves HTML/CSS/JavaScript and images. Cloudflare Worker/D1 back-end API code and private environment bindings are **not** included. Some functions requiring `/api/challenges/`, `/api/openings/`, or `/api/visits/` will not work until a separately hosted, secure API is configured. Supabase connectivity depends on project settings.

To publish: GitHub repository > Settings > Pages > Build and deployment > Source: Deploy from a branch > Branch: main > /(root) > Save.

Production site is kept separate on Cloudflare Pages.
